# 思想与设计

> **态度：** 你就是你，你本来就很好  
> **使命：** 用行为设计让自律自然发生  
> **价值承诺：** 通过科学的方法，成为你想成为的那个你

本文由团队学习笔记整理为对外说明，不构成医疗建议。

BeYourSelf 相信：少靠硬扛意志力，多用环境、习惯与反馈，让目标行为更容易发生。下面是我们据此做产品时依赖的共识。

## 自律的科学定义

在心理学中，「自律」通常对应 **自我控制（self-control）** 与 **自我调节（self-regulation）**：

| 概念 | 含义 | 日常例子 |
|------|------|----------|
| **自我控制** | 抑制当下冲动或习惯性反应，以符合长期目标 | 忍住不刷手机、按时睡觉 |
| **自我调节** | 监控并调整想法、情绪与行为，朝向目标 | 计划、反馈、情绪调节 |
| **执行功能** | 抑制控制、工作记忆、认知灵活性等能力 | 自律的「硬件」底座 |

一句话：**自律不是「对自己狠」，而是在冲突情境中，让长期身份与目标仍能驱动行为。**

### 常见误解对照

| 误解 | 我们的立场 |
|------|------------|
| 自律 = 惩罚自己、消灭欲望 | 欲望是信息；问题在线索—反应回路与目标冲突，不是道德缺陷 |
| 自律 = 意志力够强就行 | 意志力有限且波动大；环境与默认路径往往决定行为 |
| 做不到 = 人品差、不够好 | 失败多来自设计不当；你本来就很好——缺的是可执行的系统 |
| 一次破戒 = 全盘失败 | 全有或全无思维会放大「破窗」；需要重启规则与自我同情 |

这也与自我决定论一致：当行为来自自主、伴随胜任感与关联感时，动机更可持续。路线不是「逼你变成另一个人」，而是澄清你想成为的身份，降低摩擦，并在挫折时保护自尊。

## 为什么难

### 双系统：冲动 vs 控制

行为常是两套过程的竞争：

- **冲动系统**：快、自动、线索驱动（通知红点、零食气味、沙发）
- **控制系统**：慢、耗费注意、依赖目标与规则

线索强、疲劳、压力大、目标模糊时，冲动系统更容易赢。因此产品不该只教「忍」，而要削弱不良线索、增强目标线索，并在关键窗口给出轻量行动。

### 环境与线索

同一人在不同环境里，表现可以判若两人。提示线索会自动激活习惯；摩擦决定行为是否发生；默认选项会塑造结果。核心杠杆之一是 **环境与默认路径设计**，而不只是内容激励。

### 少做意志力恐吓

「自我耗竭」假说后续争议很大。更稳妥的看法是：关键的是动机、信念、情绪与机会成本；疲劳与压力会改变偏好。少做「意志力电量条」式恐吓，多做能量管理、任务切分、成功体验与重新开始。

## 可引用的科学底座

不必在界面堆术语，但设计应对齐这些机制。

### 习惯回路：线索 → 行为 → 奖励

改习惯的关键通常不是消灭欲望，而是 **保留线索与奖励，替换中间行为**，或 **改变线索环境**。

### 实施意图（if-then）

预先约定：「如果出现情境 X，那么执行行为 Y。」把临场决策外包给情境，减少意志力消耗。例如：晚上 22:30 就把手机放进客厅充电盒。

### Fogg 行为模型（B=MAP）

行为发生需要 **动机 × 能力 × 触发** 同时到位。优先让行为足够容易（提高能力、降低要求），再配合触发；动机波动大，不宜作为唯一杠杆。Tiny Habits 的思路：从「想改变人生」降维到锚定后的微行为，用成功体验滚雪球。

### 自我决定论（SDT）

可持续动机依赖三种需要：**自主**（这是我选的）、**胜任**（能看到进步）、**关系**（被理解而非孤立比较）。「你本来就很好」保护自主与自尊；科学方法提供胜任路径。

### 自我同情

挫折后友善对待自己，更利于再尝试。破戒后引导重启，而非惩罚——与「一次失败不等于全盘失败」一致。

## 实现路径：优先顺序

可组合的干预很多；与「行为设计让自律自然发生」一致的默认顺序是：

1. **先环境** — 降低依赖意志力的频率  
2. **再微习惯** — 用小胜建立胜任感与自动化  
3. **再目标与反馈** — 把行为连到「想成为的你」  
4. **辅以规则与承诺** — 对付少数高风险缺口  
5. **贯穿认知情绪与自我同情** — 保护长期关系（用户与自己）  
6. **始终看守能量** — 没有睡眠与恢复，再好的设计也会失效  

```text
身份与价值（你想成为谁）
        ↓
环境默认路径 + 微习惯 + 触发
        ↓
短反馈环 + 胜任感
        ↓
复盘与温和调整（非羞耻）
```

具体功能如何取舍，见 [设计原则](./principles)。
