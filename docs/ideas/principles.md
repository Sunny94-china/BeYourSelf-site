# 设计原则

BeYourSelf 做功能与文案时，默认遵守：

1. **设计重于说教** — 使命是行为设计，不是鸡汤订阅号。
2. **自主重于监控** — 「你本来就很好」；避免羞辱型连续打卡绑架。
3. **微小重于宏大** — 优先让下一步极易完成。
4. **身份重于条目** — 清单是手段，目标是成为你想成为的那个你。
5. **科学可叙述、体验要简单** — 内部可对齐理论，界面不堆术语。

## 功能自检

- 它降低的是摩擦，还是只增加了压力？
- 它增强的是自主与胜任，还是内疚与比较？
- 用户失败时，路径是重启，还是惩罚？
- 它是否让「正确行为」比「错误行为」更容易一点？
